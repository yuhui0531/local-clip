# 验收与证据执行手册

> 来源：[PRD](../PRD-macOS剪贴板管理器-2026-10-09.md) AC01–AC27。
> 日期：2026-10-09。状态：所有应用测试未执行。

本文件给出开发任务与验收的对应关系、可重复输入和判定方式。它不替代 PRD，不把自动测试通过当作真实目标应用接收成功。

## 1. 四种证据分别记录

| 层级 | 内容 | 能证明什么 |
|---|---|---|
| U 单元 | 纯规则、fake Clock、fake 系统边界 | 分支、排序、状态转换符合约定 |
| I 存储/集成 | 临时文件 SQLite、实际文件大小、子进程中断与重启 | 持久化、事务、物理空间与恢复行为 |
| M 真实应用 | 系统剪贴板、真实权限、真实目标应用 | 用户可见效果、真实格式与接收结果 |
| P 性能 | 指定硬件/系统/构建和固定数据集 | 该条件下的延迟、资源与容量行为 |

一个 AC 可需要多种证据。要求 M 的项目只有 U/I 通过时仍未完成。测试状态固定为未执行、通过、失败、受阻；测试退出码非零不改写成“部分通过”。

## 2. 数据与环境隔离

- 测试数据库放到独立临时目录，所有测试接受注入的 StorageLocation。仅 Debug/测试构建允许 `LOCALCLIP_DATA_DIR`，Release 忽略该覆盖。
- 自动测试默认只使用 fake 或专用命名 pasteboard，不写系统 general pasteboard；真实系统操作在 M 阶段明确进行。
- 所有输入由 Fixtures 生成，不读取用户 Paste 历史、密码管理器正文或真实客户信息。
- M 阶段保存证据前清空专用测试应用中的无关内容；测试操作会改变剪贴板，记录这一事实，不承诺可以完整备份和恢复任意第三方剪贴板对象。
- 权限授权、登录启动开启等需要用户的系统操作时，将具体步骤列出。仅在测试中读取状态不自动修改系统数据库。
- 时间边界使用 fake Clock，禁止修改系统时间来通过期限测试。

### 固定 fixture 清单

| ID | 内容 / 结构 | 目的 |
|---|---|---|
| TXT-A/B/C | `LOCALCLIP-TEST-A`、`LOCALCLIP-TEST-B`、`LOCALCLIP-TEST-C` | 顺序、恢复、去重 |
| ZH | `今天整理需求，明天处理代码。` | `需求`、`代码` 和单字查询 |
| CODE | 含 `foo_bar`、`50%`、引号、反斜杠、`a->b`、空格的多行代码 | 字面检索、不解释查询语法 |
| URL | `https://example.invalid/path?a=1&b=2#section` | URL 片段，不触发网络访问 |
| RICH | 同一中文句子分别以 plain/RTF/HTML 表示，包含加粗、斜体、链接和换行 | 原格式、纯文本、同字不同格式 |
| IMG | 固定种子的 PNG/TIFF/JPEG，已知宽高、色块和像素；另有超过40MP的样例 | 恢复、预览限制、内存 |
| MULTI | 两个文本 item；文本+图片；混合一个无支持格式的 item | 顺序和整次跳过规则 |
| PRIVATE | 同 TXT-A，但分别添加完整 ConcealedType/TransientType 类型；多项仅一项带标记 | 先过滤、整次过滤 |
| SOURCE | 声明测试 bundleID、无来源、冲突来源三组 | 排除/未知规则；不冒充真实来源证明 |
| TIME | firstCopiedAt 为 31 天前、lastCopiedAt 为今天；以及恰好 30 天前等边界 | 期限与取消收藏 |
| QUOTA | 逻辑与实际物理占用受控的合成库、共享 BLOB 和待回收文件 | 配额边界、清理统计 |

配额单元测试可用注入计量器精确构造数值；I 测试必须创建真实文件并报告实际字节数。不得要求 SQLite 含索引的物理文件恰好等于正文长度，也不得将 fake 的 490MiB 结果冒充真实数据库测量。

T00 填具体版本，T19 填执行结果和证据。下面是要求验证的组合，不是已通过列表。

| 目标 | 纯文本手动/直接 | 富文本原格式/纯文本 | 图片 | 额外检查 |
|---|---|---|---|---|
| TextEdit 纯文本模式 | 必测 | 只接受纯文本的自然结果，不能据此判定富文本恢复失败 | 不承诺 | 换行、中文、代码 |
| TextEdit 富文本模式 | 必测 | 必测RTF及HTML已声明属性 | 必测 | 原格式与纯文本差异 |
| Safari 本地测试页 textarea/contenteditable | 必测 | contenteditable测简单HTML | 不承诺通用网页图片粘贴 | 焦点/权限、字面符号 |
| Chrome 本地测试页 textarea/contenteditable | 必测 | 同上 | 不承诺通用网页图片粘贴 | 与Safari分别记录 |
| VS Code 未保存纯文本文件 | 必测 | 纯文本结果 | 不承诺 | 缩进、引号、符号 |
| Pages 空白文档 | 必测 | 必测RTF及简单HTML | 必测 | 办公场景真实接收 |
| Microsoft Word | 可选扩展 | 可选扩展 | 可选扩展 | 不代替Pages必测，也不自动扩大支持承诺 |

测试页只包含本地 fixture，无账号、提交动作或外部资源。Pages 不可用时可在 T00 明确以 Word 作为办公验证目标并记录原因，不把所有办公软件泛称“支持”。最低 macOS 15 与实施机器当前系统分别记录，无法获得最低版本环境时兼容验收受阻。

对每个必测格按“源应用复制 → 历史可见 → 选择恢复 → 目标实际接收 → 核对内容/格式”执行。直接粘贴关闭权限、正常权限各一组；系统权限由用户操作。应用不支持某格式的格标注不适用并依据本表说明，不能将本产品应支持的失败改成不适用。

## 7. 性能方法

### 数据集

- 文本：10,000条，固定随机种子；中文/英文/URL/代码各有样本；约90%≤2KiB、9%在2–16KiB、1%在16–128KiB。保存生成器版本、总字节、分布及hash。
- 图片：100张固定种子截图样例，按真实编码后总量记录；目标原始总量约100MiB，覆盖PNG/TIFF/JPEG和典型1920×1080尺寸。不得用100张完全相同图片经去重后冒充图像负载。
- 配额边界：单独生成实际占用为上限90%–98%的集合，含收藏/共享内容；近配额操作不能混进基准后又被当离群值删去。

### 计时与指标

| 指标 | 起止点 | 样本与目标 |
|---|---|---|
| 面板打开 | 快捷键回调 → 第一屏可交互且内容可见 | 热态200次，P95＜150ms；冷启动另测10次 |
| 搜索 | 最后一个输入事件 → 对应queryID结果可见 | 200次固定查询，包含60ms防抖和绘制；P95＜100ms |
| 复制到可见 | 测试源完成剪贴板写入 → 条目持久化并在面板可见 | 200次文本+20次典型图片；文本/图片分别报告，基准P95＜500ms |
| 配额路径 | 输入提交 → 候选替换完成及UI刷新 | 至少30次，单独报告；列出是否影响总体目标，不删除慢样本 |
| 空闲资源 | 采集开启且剪贴板不变 | 预热后10分钟；CPU均值/P95、内存、唤醒或可获得的能耗指标 |
| 压力 | 1000/500/200/50ms间隔复制各100项 | 报告输入数、保存数、去重数、明确跳过数、未观察变化；不预设50ms必须零丢失 |

P95 使用排序后的 nearest-rank 第 ceil(0.95×n) 个样本，保存原始数据和计算方式。测量使用单调时钟，报告 OS、CPU、内存、Swift、构建类型、数据集hash、采集周期。能耗工具不可用时报告不可用，不伪造为零。

固定方案先测再优化；只有新修改或未解失败才扩大测试。优化不得改变字面搜索、完整恢复、隐私过滤和失败保留行为。

## 8. 工程创建后的执行命令

以下命令是供实施者在相应任务完成后运行的约定，当前没有执行，也不说明脚本已经存在。工作目录为 `/Users/ronny/VscodeProjects/rea`；换机器时替换项目根目录。

```sh
rtk proxy xcode-select -p
rtk proxy xcrun swift --version
rtk proxy swift build --package-path macos-app
rtk proxy swift test --package-path macos-app
rtk proxy bash macos-app/scripts/build-app.sh debug
rtk proxy bash macos-app/scripts/build-app.sh release
rtk proxy bash macos-app/scripts/benchmark.sh
```

`build-app.sh` 在任意cwd可运行，定位自己的工程根；输出固定到 `macos-app/dist/LocalClip.app`。脚本不得自动启动登录项、修改权限、读取Paste目录或发布产物。`benchmark.sh` 只使用测试目录，不覆盖开发历史；原始性能数据写到独立证据目录。

如果 Swift 测试需要写模块缓存而被沙箱限制，优先将缓存放到工作区可写位置；不能把缺缓存权限误报为业务测试失败。完整 Xcode 不存在时可继续 SwiftPM 测试；不要声称已经运行 XCUITest。

## 9. 证据目录与最终交付

建议在工程内生成以下目录，测试时才创建：

```text
macos-app/evidence/
  automated/<run-id>/        # 命令、退出码、测试报告、临时库校验摘要
```

`docs/acceptance-results.md` 每行记录：AC/E编号、层级、环境、输入fixture、实际结果、通过/失败/受阻、证据相对路径、代码提交或源码版本标识、未验证范围。
