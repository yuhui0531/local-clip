## 现状（供定位）

- 表格：`HistoryManagerView.swift` 的 `ManagerTable.table`（约 197 行起），`Table(model.rows, selection:)`。右键菜单的目标规则见 `contextMenu(forSelectionType:)`：右键已选中的行，作用于 `model.targetIDs`，包括跨页全选，并带上 `selectAllID`；否则只作用于被点的那几行。
- 侧栏：`ManagerSidebar`（约 58 行起），分类行是 `Label { Text(category.name) } icon: { CategoryDot(...) }`，标签为 `.tag(Scope.category(id))`。
- 写入：`HistoryManagerModel.setCategory(_:_:_:selectAll:)` → `apply(...)`。这里已经处理了内容隐藏、正在全选、全选过期、确认，以及撤销和提示。
- 项目里还没有 SwiftUI 的 `draggable` 或 `dropDestination`。拖到其他应用用的是 `ContentExportProvider` 里的 AppKit `NSDraggingSource`，和这次需求无关，不要复用到这里。

## 要求

1. 拖动来源（表格行）
   - 从**已选中**的行开始拖：拖的是完整目标 `model.targetIDs`，包括跨页全选，并带上开始拖时的 `selectAllID`。规则和右键菜单一致。
   - 从**未选中**的行开始拖：只拖这一行。是否顺手把选择改成这一行，请按 macOS 习惯定，并在报告里说明。
   - 拖动预览显示条数，例如“3 条记录”；单条显示名称或首行。内容隐藏时显示“1 条记录”这类不含正文的文字。
   - 拖动数据只在本应用内使用：用私有的 UTType 只传一个令牌或 ID，模型据此解析出目标。不要把正文或文件放进拖动剪贴板，跨页全选也不要把几千个 ID 塞进去。其他应用和 Finder 应该不接受这次拖放。
   - 勾选框、铅笔和删除按钮上不要开始拖动；单击、快速连点的行为不变。
2. 放下目标（侧栏分类行）
   - 只有“分类”分区里的行可以放下。资料库和类型行不接受，“收藏”也不接受（本次不做，可在报告里提建议）。
   - 拖到分类行上方时要高亮，离开时取消高亮。
   - 放下等于“加入分类”（`setCategory(ids, categoryID, true, selectAll:)`），只加不删，也不是移动。已经在该分类里的记录不重复计入；如果全部都已在该分类，提示“已在「X」中”，不写入。
   - 完成后的提示和撤销沿用 `apply` 现有的方式，例如“已加入「回车类」3 条”，可以撤销。
   - 放下时如果全选已过期、正在收集全部或内容已隐藏，沿用 `apply` 现有的拒绝和提示，不要自己另写一套判断。
   - 放下后，侧栏当前的范围选择不变，不要跳到那个分类。
3. 内容隐藏（`hideContents`）时不允许开始拖动。

## 追加需求：打开历史管理时隐藏底部历史面板

用户原话：“打开历史记录明细的时候，屏幕下端的那个历史记录面板需要隐藏。”

现状：所有入口都走 `AppDelegate.showHistoryManager(reveal:)`（`AppDelegate.swift:793`），包括菜单栏和“窗口”菜单的“历史管理… ⌥⌘H”、面板的“更多”、卡片右键“在历史管理中显示”、面板内的 ⌥⌘H（约 1000 行）。打开时没有收起面板，面板会挡在历史管理窗口下方。

要求：
- 在 `showHistoryManager` 里统一处理：先收起面板，再显示并激活管理窗口。窗口已经打开、只是被带到前面时，也同样收起面板。
- 复用现有的 `dismissHistory(animated:)`（`AppDelegate.swift:550`），不要另写一套隐藏逻辑。它会一并关闭面板里的详情、分类编辑器、筛选和状态浮层，不激活旧的目标应用，也不改系统剪贴板。动画是否保留由你决定，原则是不要和管理窗口的出现互相闪烁。
- 收起面板后，键盘焦点必须落在历史管理窗口上，不能回到之前的目标应用。
- 管理窗口打开期间，快捷键仍然可以唤出面板，本次不禁止。如果你认为打开期间应该禁止，请在报告里提出，等用户确认再做。
- 面板的“正在粘贴”或队列提示（`queuePanel`、`feedbackPanel`）不属于这次的范围，保持不变。

验证：如果能抽成可测的纯逻辑（例如“打开管理窗口会调用收起面板”），补一个静默用例。真实界面复核时，从上面每个入口各打开一次，确认面板都已收起、焦点在管理窗口上。
