# v0.3.86（108）发布记录

## 修复

- 历史管理的 SwiftUI 默认最小行高与原生表格固定行高统一为 56 pt，避免选择更新写回 24 pt、滚动重建又恢复 56 pt。
- 行高回归覆盖首次未创建离屏行时的选择通知、SwiftUI Binding 和实际滚轮位移，同步观察所有行高写入。选择后的原生定位先完成，再验证下一次滚轮输入。
- 更新静默测试的系统兼容检查。文件详情继续检查内容撑高、整页上移和窗口尺寸。裸网址检查系统补全的 HTTP 或 HTTPS 及完整主机名。真实 Vision 识别允许最多 30 秒冷加载，仍验证识别短语能找回原图。

## 验证

原始生产代码在图片和文本两组增强回归中均出现 24 pt 行高。修复后的隐藏窗口回归检查行高、表格总高度、滚动位置、详情、窄窗口和分页。每次滚轮均要求产生实际位移。

本机使用 macOS 27.2.1、Swift 6.4.2、SDK 26.5 与 native 构建器运行静默测试。当前默认 SDK 的 SwiftUI 宏插件缺失，使用本机已有兼容 SDK 完成验证，未修改项目构建配置。

本机全量静默测试 549 项通过、0 项失败、79 项跳过。行高回归在选择定位完成前持续检查几何，随后核对每次滚轮的实际位移，原始代码的 24 pt 回退仍会被检出。

专用剪贴板协议矩阵 28 项通过、0 项失败、2 项未开启的压力门控跳过。跳过项单独记录。

发布前检查 GitHub Actions 官方维护与安全说明，现有固定提交对应 checkout v7.0.1、upload-artifact v7.0.1 和 download-artifact v8.0.1。已公开的下载解压漏洞影响 4.1.3 之前的版本。
