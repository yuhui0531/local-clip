# v0.3.85（107）发布验收

## 改动

- 历史管理先显示窗口和加载状态，首页查询完成后填表。
- 数据库迁移、补表、日志恢复或库文件变化后重新校验。恢复检出损坏时将存储标记为不可用。启动恢复失败时显示存储恢复弹窗。
- 快速预览按文件项显示历史副本提示，多文件详情只提示可执行的恢复操作。
- 保留 Release 基准入口。依赖 Debug 接口的测试仅在 Debug 编译，基准可直接从仓库运行。

## 实测

历史管理用 341 条合成记录的隔离库复测。每种条件下改动前后各五次，从打开请求计到窗口达到 10% 不透明度。

| 条件 | 改动前中位数 | 改动后中位数 |
| --- | ---: | ---: |
| 正常查询 | 551 ms | 382 ms |
| 查询额外延迟 500 ms | 1071 ms | 212 ms |

延迟场景下，改动后五次均先显示加载状态，再填入首页 50 条记录。首页查询就绪耗时未见缩短。另从实际菜单打开，确认列表和 341 条总数可见。

启动恢复用另一份含 341 条合成记录的隔离库复测。验收包在打开数据库后暂停，注入一条外键异常记录，再执行正常恢复路径。弹窗报告完整性检查失败。点击「在访达中显示数据目录」，访达选中隔离目录，原进程继续运行。移除异常记录后，SQLite 快速检查返回 `ok`，外键检查无异常，记录数仍为 341。点击「重试」后同一进程进入历史面板。两个按钮响应依次为 `1001` 和 `1000`。

失效文件通过临时库自动化用例验证。含两项的记录在原件均缺失时，逐项显示有副本和无副本的提示。预览阶段保持原始引用，复制时恢复已保存的字节。

本机全量静默测试 549 通过、0 失败、79 跳过。Release 存储及隐藏面板基准 4 通过、0 失败、0 跳过。
