# 界面实现

2026-10-10 用户追加要求：界面类似 Paste，不能交付简陋半成品。
采用底部横向卡片面板：当前显示器全宽×380pt，固定屏幕底边，不可拖动；圆角与系统磨砂材质；历史/收藏一级入口；字面搜索与内容类型筛选；250×200pt内容卡片。
来源名称与本地应用图标、分类型色彩、图片按需缩略图、文字大预览、代码等宽深色显示、链接地址卡、完整详情popover、收藏和操作栏。未知来源明确显示；复制时前台应用推断与应用声明分别标注依据，APP图标来自公开AppKit。
方向键、Enter、Escape、Command-C；中文marked text优先给输入法。详情依然读取完整原始内容，卡片摘要不会成为恢复数据。

此调整替代 design §7 建议的900×460/列表+详情布局，行为与存储技术基线保持。所有图标为SF Symbols或公开系统接口获取的目标应用图标，未访问 Paste.app。

`--render-ui` 仅Debug视觉测试入口：合成fixture写真实临时SQLite，使用命名pasteboard，不触碰general。导出的是实际SwiftUI视图像素，属于视觉渲染证据，不能代替真实目标应用验收。Release不包含该入口，也不注入fixtures。

实际面板已由CUA打开并记录C/B/A顺序及TextEdit接收，见evidence/manual/20261010-resume。再次打开应用直接展示历史。到期截止任务即时撤销卡/详情/恢复资格，第一页到期后重新查询，使旧收藏仍可见。

## 0.1.11 分类（历史布局，已替代）

分类条位于搜索/历史入口与类型筛选之间，横向滚动；右侧固定新建入口，当前分类显示重命名铅笔。右键分类可重命名；记录右键加入分类，底部分类菜单显示当前归属并支持切换。分类页面提供引导空态；名称对话框置于底部面板之上。全宽固定底部面板增高至490pt，原横向历史滚动/Esc/失焦/快捷键切换保留。真实外观与交互尚未执行验收。

## 0.1.12 紧凑与稳定布局

当前固定底部380pt，卡片250×200pt；工具栏与预览同步压缩，详情保留完整内容。独立behindWindow磨砂背景alpha0.78，正文/卡片alpha不降；state固定active，系统降低透明度时alpha1。加载指示与右侧动作始终保留位置，选择只改变启用/高亮；首次挂载前就确定显示器全宽，不使用1400pt可见过渡。⌫/⌦删除当前记录（保留确认），文字搜索与中文输入优先编辑。实际外观和闪烁效果尚未执行验收。

## 0.1.13 同行分类

类型分类与自定义分类共用一行横向滚动区域，类型入口全保留。自定义标签为彩色圆点+名称，选中浅色胶囊；新建＋固定在该行末尾。右键标签重命名，新建/重命名使用＋位置的面板内popover，错误就地显示，不再弹原生模态名称对话框。编辑键盘与输入法不触发历史动作，owned popover焦点受保护。颜色稳定由ID派生；无迁移/颜色存储变更。继续使用380pt固定全宽底部、250×200pt卡片及透明背景。尚未做GUI或视觉验收。

## 0.1.14 拖拽分类

所有历史卡片增加原生onDrag。自定义标签用独立State维护拖入高亮，显示彩色底色/边框，不切换查询范围；松开后复用现有归属提交。预览只显示加入分类；不导出正文或文件路径，类型标签不接收拖放。单击、双击、横向滚动与右键入口保留。实际拖拽交互尚未验收。
