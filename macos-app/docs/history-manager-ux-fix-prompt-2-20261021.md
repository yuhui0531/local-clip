## 方案

### 1. 记录信息并入来源行（替代默认展开）

现状：`ManagerDetail` 里的 `ClipRecordInfo`（`HistoryView.swift:1382` 附近，面板与管理窗口共用）是一个默认折叠的 `DisclosureGroup`。`ManagerDetail` 按 `.id(row.id)` 重建，每选一条新记录都会重新折叠。

要求：
- 管理窗口检查器中，标题下的来源行改为一行常显信息：`来源 · 复制 N 次 · 最近 <时间> · <大小>`，例如 `微信 · 复制 3 次 · 最近 10月21日 17:33 · 110 bytes`。
- 格式类型（UTI，如 `public.utf8-plain-text`）不常显：放进悬停提示，或放进一个小的“格式详情”折叠项。
- `ClipRecordInfo` 里的说明文字（文件引用提示、“仅保留支持格式”）在管理窗口继续直接显示。
- 修正来源重复：`HistoryView.sourceDescription` 在来源未知时显示为“未知 · 来源未知”。来源未知时只显示“来源未知”。改这里会影响面板，请确认面板的显示也是改进，否则只在管理窗口生效。
- 底部面板仍用原来的折叠“记录信息”。复用方式自选，例如给 `ClipRecordInfo` 拆出可复用的字段格式化，不要复制一份。
- 内容隐藏（`hideContents`）时，元数据的显示规则与现有规则保持一致。

### 2. 详情区：预览填满检查器剩余高度

现状：
- 预览用的是共用的 `ClipDetailPreview` → `SyntaxDetailPreview`。高度由 `InspectorPreviewLayout.height(for:)`（`InspectorPreviewLayout.swift:6-11`）按 **444pt 宽**测量，结果限在 52–200pt。
- 管理窗口检查器默认 320pt（`inspectorColumnWidth(min: 280, ideal: 320, max: 440)`），实际文字区约 300pt。文字折行更多，高度却是按 444pt 算的，于是长文被截断，也没有滚动条（用户截图：SQL 记录只显示四行，第四行被切掉一半）。
- 外层 `ScrollView { ClipDetailPreview(...) }.frame(maxHeight: .infinity)` 给了空间，但内部固定高度没有用上。

要求：
- 给共用预览加一个**只在管理窗口使用**的填充模式：预览区占满检查器里名称、来源行、分类、按钮之外的全部高度，长文在预览区内部滚动；图片按可用空间等比放大。底部面板继续用 `InspectorPreviewLayout` 测高，不受影响。
- 检查器布局：名称和来源行在顶部，分类、格式详情、附加按钮、“复制”在底部固定，中间是可伸缩的预览区。
- 检查器加宽：默认约 400pt，最小 300pt，最大 640pt，可拖动调整；如果 SwiftUI 不能自动记住宽度，说明一下即可，不必为此自建持久化。
- 加宽后，在 1180×820 默认窗口下核对名称列是否仍可用（第一轮复核里名称列只占表格约 43%）。若两者冲突，给出取舍建议，不要擅自隐藏列。
- **可选（先评估再做）**：按空格，或在预览区点“放大”，用一个大附页只读显示全文，复用 `ClipDetailPreview` 的填充模式。注意空格不能和表格的键入查找冲突，也不能在编辑或输入框获得焦点时触发。

### 3. 多选：检查器只显示汇总

现状：`ManagerInspector` 多选时显示“已选择 N 条”和 `targetNames` 逐条名称列表（`HistoryManagerView.swift:311-316`）。

要求：
- 去掉逐条名称列表，也去掉检查器里重复的“已选择 N 条”标题（数量只保留在批量栏）。
- 改为汇总：
  - 类型分布，例如“文本 12 · 链接 5 · 图片 2”；
  - 已收藏条数；
  - 涉及的分类（色点 + 条数）；
  - 复制时间范围（最早 – 最近）。
- 数据来源：
  - 本页多选：直接用 `rows` 和 `memberships`。
  - 跨页全选：`selectAllMatching()` 的循环里已经拿到每页的 `ClipSummary`，在同一循环里统计类型计数和 `lastCopiedAt` 的最小值、最大值，和现有的 `allFavorites`、`allMemberships` 放在一起。**不新增任何查询**。全选作废或取消时一并清空。
- 正在收集全部时，显示现有的“正在选择全部…”状态即可。

### 不要做

- 多选时自动收起检查器：表格宽度会随选择变化，界面会跳。
- 把批量按钮搬进检查器：偏离已确认的设计。
- 改成“左列表 + 右侧大预览”的整体布局：改动过大，本轮不做。
