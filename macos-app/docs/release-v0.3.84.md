# v0.3.84（106）发布验收

## 改动

- 存储打开失败时，定位数据目录后继续显示恢复弹窗。仅明确的退出响应结束进程。首次恢复失败后，重试会检查数据库完整性与外键。
- 失效文件卡片显示副本可用情况，详情汇总未展开的项目。打开详情不生成拖出文件。正文损坏时，复制显示对应错误。
- 预热面板跳过 32 ms 等待，粘贴回退与连续按键处理保留单次操作。满配额时，库和目录占用不变的重复探测复用预演结果。

## 验收

- 隔离桌面包使用版本 99 的测试库。访达选中隔离目录后，同一进程继续运行并重新显示弹窗。依次记录定位、重试、退出响应 `1001`、`1000`、`1002`。库文件 SHA-256 前后一致。换入有效隔离库后，重试成功进入历史。
- 三条合成文件记录各有六项，分别覆盖缺失原件全部、部分和均无副本。详情正确展示前四项，末两项均失效，对应副本数为 2、1、0。查看详情后没有生成 `DragFiles`。
- 应用程序目录中的已安装 v0.3.83 成功载入现有历史，并可打开已有记录的详情。
- 本机最终全量静默测试连续五次均为 546 通过、0 失败、79 跳过。采集套件独立调度后，两种参数合计 55–66 ms。
- Release 隐藏面板对照及满配额预演数据见 [性能基线](performance.md)。首屏已准备时，隐藏面板提交 P50 缩短约 33 ms。满配额连续调用时，首次完整预演与第二次缓存命中的元数据请求 P95 分别为 1591.16 ms 和 49.65 ms。

## 本次发布的原生验收豁免

按维护者授权，对本候选版尚未完整执行的原生验收使用豁免。范围包括普通与减弱动态效果下的可见首帧、完整界面和辅助功能权限矩阵、实际目标应用的粘贴与拖放矩阵、B01–B09 性能矩阵，以及候选包直接读取正式历史库。上述隔离验证和已安装版本验证分别计入实际通过项。GitHub Actions 的静默回归、专用剪贴板协议、打包校验及更新签名继续作为发布条件。
