# 用户确认的交互约定

- 始终后台工具：不出现 Dock 和苹果旁 LocalClip 应用菜单；右侧状态栏图标及已有快捷键保留。
- 卡片、历史管理、设置仅一个主界面可交互；切换收起原界面的图片/文件预览及浮层。
- 关闭回原外部应用，不自动返回上一个 LocalClip 界面；重复普通窗口入口只前置/恢复最小化。
- 离开管理窗口释放视图、模型、查询及预览；仅保留分类范围、搜索、排序。重开读取最新数据，不恢复多选、页码/滚动位置。
- 设置关闭释放；重开恢复分组和最新已保存配置。
- 普通设置即时保存；未提交名称等有变更则保存并继续/放弃修改/取消切换，保存失败保留原界面和输入。
- 录制快捷键切换时取消，保留原值，不加弹框。手动应用存储限制沿用原有破坏性确认，不隐式写入。
- 现有确认弹框优先：新切换不执行、不排队，不自动选择；前置原弹框。Esc只取消弹框。
- 切换本身触发的编辑保护保留原目标，期间新请求不能替换。
- 克制原生动效，无明显反弹。卡片小幅位移和淡化，普通窗口以淡化为主。内容/布局先就绪，无闪白/突然撑开。
- 动画可打断，从当前状态衔接最新有效目标，不积压。退出动画后释放窗口；过渡期间只一个主界面可交互。
- 减少动态效果时短淡化无位移。

测试与发布：用户要求独立 review agent 复审，修复后发布新版本。本轮未新授权可见桌面交互；隐藏窗口/替身测试与真实桌面动效严格区分。
