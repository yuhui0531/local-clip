## English

### 🌟 Overview

**LocalClip** is a lightweight, high-performance clipboard management tool built natively for macOS (Apple Silicon). It brings the beloved, elegant horizontal card drawer UI (similar to Paste) to your desktop, while prioritizing **100% local privacy**, instant responsiveness, and seamless integration with macOS system workflows.

Whether you are copying plain text, rich formats (RTF/HTML), code snippets, high-resolution images, URLs, or Finder file objects, LocalClip handles them effortlessly with zero network requests and robust local storage.

---

### ✨ Key Features

#### 🔒 100% Local & Privacy-First
- **Zero Network Access**: No cloud sync, no tracking, and no external requests. All clipboard records stay strictly on your local Mac.
- **Sensitive Data Filtering**: Automatically ignores transient and confidential items from password managers (1Password, Bitwarden, Apple Keychain, KeePassXC) marked with standard pasteboard concealment flags (`org.nspasteboard.ConcealedType`, `AutoGeneratedType`).
- **Quota & Retention Rules**: Configurable storage limits (default 500 MiB) and retention periods (default 30 days). Expired ordinary items are purged automatically, while favorites and pinned categories are strictly preserved.

#### 🎨 Paste-Style Native Bottom Drawer UI
- **Docked to Screen Bottom**: Smooth horizontal drawer spanning the full width of your current monitor, adapting seamlessly to Light and Dark modes.
- **Multi-Kind Content Rich Cards**:
  - **Code**: Automatic programming language detection, syntax highlighting, monospaced font, and hanging indentation for code wrapping.
  - **Images**: High-efficiency in-memory thumbnail generation using ImageIO, with safe limits preventing memory bloat on giant images (>40 MP).
  - **Files**: Native Finder file object references, allowing instant file previews and quick actions ("Show in Finder" / "Open With...").
  - **Rich Text & Links**: Preserves original RTF/HTML formatting and highlights URLs with domain badges.
- **Unified Single-Row Toolbar**: Quick access to **Clipboard (All)**, **Favorites**, type filters (Text, Link, Image, File), and custom categories in a clean, uncluttered layout.

#### 🪄 Smart Paste & Frictionless Workflow
- **Double-Click Direct Paste**: Single-click to select; double-click a card to restore original clipboard formats and automatically paste directly into the previously focused application without touching the Enter key.
- **Smart Code File Pasting**: When copying code files, LocalClip intelligently pastes the file's text contents when targeting code editors (VS Code, Xcode, Zed, terminal), while preserving the actual file object when pasting into Finder.
- **Card Renaming (v0.3.12+)**: Double-click the colored card header or select **Rename** from the context menu to give any clipboard item a memorable custom name. Press `Enter` to save, `Esc` to cancel, or clear the text to restore defaults.
- **Drag-and-Drop Categorization**: Effortlessly organize clips by dragging cards into category tabs. Items within a category maintain convenient newest-first ordering.

#### ⚡ Blazing Fast Performance
- **Swift 6.2 & SQLite WAL Engine**: Native AppKit + SwiftUI architecture backed by a robust SQLite persistence layer with atomic fault-tolerant commits.
- **Sub-Millisecond Queries**: Paginated memory caching, viewport-driven progressive rendering, and instant literal search across Chinese phrases, code symbols, and URL fragments.
- **Zero Startup Lag**: Automatic monitoring resumes seamlessly upon storage recovery without requiring manual activation.

### 🛠️ Architecture & Tech Stack

```text
LocalClip/
├── LocalClipCore        # Pure Swift domain models, SQLite persistence, quota/retention engine
├── LocalClipMac         # Native pasteboard monitoring, Carbon hotkeys, AppKit/SwiftUI drawer UI
└── LocalClip            # AppKit lifecycle entry point and single-instance manager
```

- **Frameworks**: Swift 6.2, SwiftUI, AppKit, Combine, SQLite3, ImageIO.
- **Target OS**: macOS 15.0+ (Sequoia) on Apple Silicon (M1/M2/M3/M4).

### 🚀 Getting Started

#### Requirements
- macOS 15.0 or later
- Apple Silicon Mac
- Xcode 16+ / Command Line Tools with Swift 6.2

#### Build & Run
From the project root:

```bash
# Build the release application bundle (creates dist/LocalClip.app)
bash macos-app/scripts/build-app.sh release

# Open the built application
open macos-app/dist/LocalClip.app
```

> **Note**: For Direct Paste to work seamlessly, please grant **Accessibility** permissions to `LocalClip.app` in `System Settings -> Privacy & Security -> Accessibility`.

## 简体中文

### 🌟 项目简介

**LocalClip** 是一款专为 macOS（Apple Silicon）打造的高性能、纯本地剪贴板管理工具。它带来了类似 Paste 优雅经典的**底部横向卡片抽屉**交互，同时严格坚持**100% 本地隐私**、毫秒级响应以及丝滑的原生系统契合度。

无论是纯文本、富文本 (RTF/HTML)、代码片段、高分辨率图片、网络链接，还是 Finder 真实文件对象，LocalClip 都能轻松记录与管理，无任何网络请求，全面保障您的数据安全与隐私。

---

### ✨ 核心特性

#### 🔒 100% 纯本地与隐私优先
- **零网络连接**：无云端上传、无用户追踪、无第三方联网 SDK。所有剪贴记录仅保存在 Mac 本地 SQLite 数据库中。
- **敏感数据智能过滤**：自动识别并忽略密码管理器（如 1Password、Bitwarden、Apple 钥匙串、KeePassXC）带有敏感或临时标记的内容（`org.nspasteboard.ConcealedType`、`AutoGeneratedType` 等）。
- **空间配额与自动淘汰**：支持自定义历史保留期限（默认 30 天）和存储上限（默认 500 MiB）。达到配额后自动清理过期普通记录，已收藏及自定义分类项受到严格保护不被淘汰。

#### 🎨 Paste 风格原生底部横向抽屉 UI
- **贴合屏幕底边**：展开时自适应吸附在当前显示器底部，全宽展示，完美适配 macOS 浅色与深色外观。
- **多类型内容自适应高亮卡片**：
  - **代码 (Code)**：自动识别语言、语法高亮渲染、等宽字体及段落悬挂缩进排版。
  - **图片 (Image)**：利用 ImageIO 内存级高效渲染缩略图，针对超过 4000 万像素（40 MP）超大图具备防爆内存保护机制。
  - **文件 (File)**：原生 Finder 文件对象引用，支持文件类型图标、在 Finder 中定位及“打开方式…”菜单。
  - **富文本与链接**：完整保留原始 RTF/HTML 排版格式，链接卡片清晰呈现域名标识。
- **单行整合式工具栏**：将**“剪切板”（全部历史）**、**“收藏”**、**类型过滤器（文本/链接/图片/文件）**与**自定义分类标签**收归于单行工具栏，清爽直观。

#### 🪄 智能粘贴与高效交互
- **双击自动粘贴**：单击卡片选择，**双击正文**即可将历史内容恢复至系统剪贴板，并自动粘贴到唤起前的目标应用焦点，无需回车。
- **代码文件智能粘贴**：复制单个或多个代码文件后，粘贴到代码编辑器（VS Code、Xcode、Zed、终端等）时智能粘贴其代码文本，粘贴到 Finder 等常规软件时保持文件引用不变。
- **卡片自定义重命名（v0.3.12+ 新增）**：双击卡片彩色头部或在右键菜单中点击**“重命名”**，即可为任意剪贴记录赋予易记标题。按 `Enter` 保存，`Esc` 取消，清空名称即可恢复默认。
- **拖拽与分类整理**：支持将历史记录直接拖拽到分类标签中归档，单个分类内采用便捷的“最新优先”排列。

#### ⚡ 极致流畅的性能表现
- **Swift 6.2 + SQLite WAL**：纯原生 AppKit + SwiftUI 构建，结合 SQLite WAL 模式与提交前故障保护，保障数据零丢失。
- **亚毫秒级检索响应**：只读页面缓存预热、分批查询收窄与虚拟按需加载，即时检索中文短词、代码符号与链接片段。
- **免手动操作即启**：应用启动在数据存储恢复后自动监听新变化，支持随时一键临时暂停或定时暂停。

- macOS 15.0 (Sequoia) 或更高版本
