### 🌟 项目简介

**LocalClip** 是一款专为 macOS（Apple Silicon）打造的高性能、纯本地剪贴板管理工具。它带来了类似 Paste 优雅经典的**底部横向卡片抽屉**交互，同时严格坚持**100% 本地隐私**、毫秒级响应以及丝滑的原生系统契合度。

无论是纯文本、富文本 (RTF/HTML)、代码片段、高分辨率图片、网络链接，还是 Finder 真实文件对象，LocalClip 都能轻松记录与管理，无任何网络请求，全面保障您的数据安全与隐私。

---

### ✨ 核心特性

#### 🔒 100% 纯本地与隐私优先
- **零网络连接**：无云端上传、无用户追踪、无第三方联网 SDK。所有剪贴记录仅保存在 Mac 本地 SQLite 数据库中。
- **敏感数据智能过滤**：自动识别并忽略密码管理器（如 1Password、Bitwarden、Apple 钥匙串、KeePassXC）带有敏感或临时标记的内容（`org.nspasteboard.ConcealedType`、`AutoGeneratedType` 等）。
- **空间配额与自动淘汰**：支持自定义历史保留期限（默认 30 天）和存储上限（默认 500 MiB）。达到配额后自动清理过期普通记录，已收藏及自定义分类项受到严格保护不被淘汰。

#### 🎨 Paste 风格原生底部横向抽屉 UI
- **贴合屏幕底边**：展开时自适应吸附在当前显示器底部，全宽展示，完美适配 macOS 浅色与深色外观。
- **多类型内容自适应高亮卡片**：
  - **代码 (Code)**：自动识别语言、语法高亮渲染、等宽字体及段落悬挂缩进排版。
  - **图片 (Image)**：利用 ImageIO 内存级高效渲染缩略图，针对超过 4000 万像素（40 MP）超大图具备防爆内存保护机制。
  - **文件 (File)**：原生 Finder 文件对象引用，支持文件类型图标、在 Finder 中定位及“打开方式…”菜单。
  - **富文本与链接**：完整保留原始 RTF/HTML 排版格式，链接卡片清晰呈现域名标识。
- **单行整合式工具栏**：将**“剪贴板”（全部历史）**、**“收藏”**、**类型过滤器（文本/链接/图片/文件）**与**自定义分类标签**收归于单行工具栏，清爽直观。

#### 🪄 智能粘贴与高效交互
- **双击自动粘贴**：单击卡片选择，**双击正文**即可将历史内容恢复至系统剪贴板，并自动粘贴到唤起前的目标应用焦点，无需回车。
- **代码文件智能粘贴**：复制单个或多个代码文件后，粘贴到代码编辑器（VS Code、Xcode、Zed、终端等）时智能粘贴其代码文本，粘贴到 Finder 等常规软件时保持文件引用不变。
- **卡片自定义重命名（v0.3.12+ 新增）**：双击卡片彩色头部或在右键菜单中点击**“重命名”**，即可为任意剪贴记录赋予易记标题。按 `Enter` 保存，`Esc` 取消，清空名称即可恢复默认。
- **拖拽与分类整理**：支持将历史记录直接拖拽到分类标签中归档，单个分类内采用便捷的“最新优先”排列。

#### ⚡ 极致流畅的性能表现
- **Swift 6.2 + 事务式 SQLite**：纯原生 AppKit + SwiftUI 构建。每次变更都是一个带回滚日志与完整落盘的 SQLite 事务，崩溃后只会是完整旧态或完整新态；保存一次复制约 3 ms，且不随历史增大而变慢。
- **快速检索**：翻页约 1 ms；数千条历史中按正文、卡片自定义名称或来源应用检索中文短词、代码符号与链接片段约 10–30 ms，并按可视区域渐进加载。
- **免手动操作即启**：应用启动在数据存储恢复后自动监听新变化，支持随时一键临时暂停或定时暂停。

### ⌨️ 常用快捷键与交互操作

| 功能操作 | 快捷键 / 交互方式 | 说明 |
| :--- | :--- | :--- |
| **唤起 / 隐藏面板** | `⌥ + ⌘ + V` (Option-Command-V) | 全局快捷键呼出底部历史抽屉 |
| **横向浏览** | `←` / `→` 方向键 或 触控板横向滚动 | 平滑翻阅剪贴板历史卡片 |
| **直接复制并粘贴** | `双击卡片正文` | 恢复原格式并直接粘贴到前台应用焦点 |
| **粘贴** | `Enter` / `Return` 键 | 将选中内容粘贴到唤起前的应用（可在设置中改为仅复制） |
| **恢复至剪贴板** | `⌘ + C` | 仅将选中的卡片内容写回系统剪贴板，不粘贴 |
| **重命名卡片** | `双击彩色顶部` 或 右键菜单「重命名」 | 行内编辑标题，按 `Enter` 保存，`Esc` 取消 |
| **查看详细元数据** | `空格键 (Space)` | 展开侧边检查器，查看来源与完整表示 |
| **退出面板** | `Esc` 键 或 单击外部区域 | 迅速关闭底部面板 |
| **退出应用** | `⌘ + Q` (Command-Q) | 安全退出 LocalClip 进程 |

### 🛠️ 技术架构

```text
LocalClip/
├── LocalClipCore        # 纯 Swift 核心库：值类型契约、SQLite 存储引擎、原子事务与配额管理
├── LocalClipMac         # macOS 原生实现：剪贴板客户端、Carbon 热键、AppKit/SwiftUI 界面体系
└── LocalClip            # AppKit 应用入口与单实例生命周期控制
```

- **开发语言与框架**：Swift 6.2、SwiftPM、AppKit、SwiftUI、Combine、SQLite3。
- **运行环境**：macOS 15.0+ (Sequoia)，适配 Apple Silicon (M系列芯片)。

### 🚀 快速上手

#### 系统要求
- macOS 15.0 (Sequoia) 或更高版本
- Apple Silicon (M1 / M2 / M3 / M4)
- Xcode 16+ 或已安装 Swift 6.2 的命令行工具

#### 构建与运行
在项目根目录下执行：

```bash
# 构建 Release 版本（产物输出至 macos-app/dist/LocalClip.app）
bash macos-app/scripts/build-app.sh release

# 打开应用
open macos-app/dist/LocalClip.app
```

> **提示**：为支持“双击直接粘贴”功能，请在系统的 **「系统设置」->「隐私与安全性」->「辅助功能」** 中授予 `LocalClip` 辅助功能权限。
